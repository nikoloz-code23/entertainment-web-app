# Entertainment Web App
The project is a responsive TailwindCSS implementation of the [Frontend Mentor Entertainment web app.](https://www.frontendmentor.io/challenges/entertainment-web-app-J-UhgAW1X)

# What does it represent?
This is a showcase that the developer can implement a complex design from Figma into a responsive for all devices website using TailwindCSS.

# How to preview the project?

To preview the project, follow the URL: https://nikoloz-code23.github.io/entertainment-web-app. Keep in mind, this is only the visuals, so when you enter the Register/Log in page, just press the Create/Login account button, to see the main page.

# How to use it?
If you want to try and edit it, simply clone the project in the following way:
```bash
# Clone with SSH
git clone git@github.com:nikoloz-code23/entertainment-web-app.git
# Or clone with HTTPS
git clone https://github.com/nikoloz-code23/entertainment-web-app.git
```
Make sure to have TailwindCSS CLI installed and input the following command in the terminal: `npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch`.
